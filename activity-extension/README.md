# Siios Activity Sync 瀏覽器擴充功能

讓您的數位活動自動同步到 Siios PWA。

## 功能特點

- 自動監聯多個平台的活動
- 隱私優先的資料收集
- 可調整的隱私等級
- 支援手動同步與自動同步
- 本地資料儲存

## 支援平台

- Twitter/X
- Instagram
- Facebook
- YouTube

## 安裝步驟

### Chrome / Edge

1. 開啟瀏覽器擴充功能頁面
2. 開啟開發人員模式
3. 點擊載入已解壓縮的擴充功能
4. 選擇 activity-extension 資料夾

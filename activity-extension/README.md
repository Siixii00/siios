# Siios Activity Sync 瀏覽器擴充功能

把電腦瀏覽器上的活動（Twitter/X、Instagram、Facebook、YouTube）同步到 Siios PWA，讓 AI 角色知道你最近在看什麼。

活動先在本機依你選的**隱私等級**過濾，再用 **AES-256-GCM 加密**，合併進你自己 GitHub 帳號的私人 Gist（和 PWA「設定 → 跨裝置同步」是同一份資料）。金鑰不會離開你的裝置。

## 安裝（Chrome / Edge）

1. 開啟 `chrome://extensions/`（Edge：`edge://extensions/`）
2. 開啟「開發人員模式」
3. 「載入未封裝項目」→ 選這個 `activity-extension` 資料夾

## 設定

先在 Siios PWA 啟用跨裝置同步（**設定 → 跨裝置同步**），並在同一頁複製 **Gist ID** 與 **加密金鑰**。然後在擴充功能的設定頁填入：

| 欄位 | 說明 |
|---|---|
| GitHub Token | 需要 `gist` 權限，**和 PWA 同一個 GitHub 帳號** |
| Gist ID | PWA 跨裝置同步頁面顯示的 Gist ID |
| 加密金鑰 | PWA 跨裝置同步頁面顯示的加密金鑰 |
| 隱私等級 | 基本（只有平台與次數）／摘要（加上標題）／詳細 |
| 要記錄的平台、同步間隔、保留天數 | 依需要調整 |

按右上角圖示開啟「活動同步」。擴充功能會依間隔把活動合併上傳，也可以在彈出視窗按「立即同步」。PWA 打開時會自動下載新的活動。

## 隱私

- 只記錄你開啟的平台，且依隱私等級過濾後才會離開瀏覽器。
- 資料上傳前加密；沒有金鑰的人（包含 GitHub）看不到內容。
- 設定（含 Token 與金鑰）只存在這個瀏覽器的擴充功能儲存空間。

# 紫微斗數 MCP 整合測試指南

## 🧪 測試頁面使用說明

已為你創建測試頁面：`test-ziwei-mcp.html`

### 測試步驟

#### 1️⃣ 測試伺服器連線
- 點擊「測試連線」按鈕
- 預期結果：✅ 連線成功
- 確認 endpoint 正確顯示

#### 2️⃣ 建立測試角色
- 填寫出生資訊（已預設測試數據）
- 點擊「建立角色」
- 預期結果：✅ 角色建立成功，顯示 ID 和資訊

#### 3️⃣ 執行命理分析
- 點擊「開始分析」按鈕（建立角色後啟用）
- 預期結果：
  - ✅ 分析完成
  - 顯示運勢摘要
  - 顯示四化（祿權科忌）
  - 顯示流年流月流日宮位
  - 顯示快取 ID

#### 4️⃣ 查看快取
- 點擊「查看快取」按鈕
- 預期結果：顯示快取的完整資料

## 🐛 常見問題排除

### 1. 連線失敗
**症狀**：測試連線顯示「❌ 連線失敗」

**檢查**：
```bash
# 手動測試 endpoint
curl https://ziwei-mcp-server.yaninlin.workers.dev/tools
```

**可能原因**：
- CORS 問題（已在 Server 端設定允許）
- 網路連線問題

### 2. 角色建立失敗
**症狀**：建立角色時出錯

**檢查**：
```javascript
// 在 Console 檢查 IndexedDB
indexedDB.databases()
```

**可能原因**：
- IndexedDB 初始化失敗
- 資料庫版本衝突

### 3. 分析失敗
**症狀**：分析時顯示錯誤

**檢查 Console 錯誤訊息**：
- `缺少出生資訊`：確認日期時間已填寫
- `缺少性別資訊`：確認性別已選擇
- `請求逾時`：網路或 Server 問題

### 4. Console 錯誤
常見錯誤：

```javascript
// 找不到模組
Uncaught TypeError: Failed to resolve module specifier

// 解決：確認 import 路徑正確
import { ziweiClient } from './js/core/ziwei-mcp-client.js';
```

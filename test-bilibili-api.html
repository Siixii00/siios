推薦解決方案

方案 1：使用 Cloudflare Workers（推薦）

方案 2：使用 JSONP（如果可用）

某些 Bilibili API 支持 JSONP，可以繞過 CORS。

方案 3：使用預設數據 + 定期更新

如果所有代理都失敗，使用預設的真實影片列表，並定期手動更新 BV 號。

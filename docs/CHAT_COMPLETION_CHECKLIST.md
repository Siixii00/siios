## 「完成」的定義（本清單的驗收標準）
一項功能算完成，必須同時滿足：
1. 使用者從 UI 點得到入口，且**不會出現「功能開發中」toast**。
2. 操作後產生**看得見的結果**（訊息出現、資料改變、頁面跳轉）。
3. **重新整理後資料還在**（寫入 IndexedDB）。
4. 失敗時有明確提示，不會卡住輸入框。
只有函式存在、或只彈 toast，一律不算。

## 根本限制（先解決，否則 + 選單多數項目做不出來）
`MessagesDB.create()`（`db.js:304`）只存 `role / content / speaker_character_id / timestamp`；`createKakaoBubble()`（`components.js:312`）只會渲染純文字。
→ 圖片、貼圖、位置、轉帳、檔案等**都沒有地方存、也沒有地方顯示**。

## 核心發現：小型 app 各自為政，大量「存了但沒人用」
| 問題 | 證據 |
|---|---|
| **設為桌布無效** | 相簿「設為桌布」寫入 `wallpaper_url`，但 `homescreen.js`／`lockscreen.js` 從不讀取 |
| **小工具不會出現在主畫面** | `widget_active` 只在小工具 app 自己的預覽用 |
| **輔助觸控的浮動球不存在** | `touch_enabled` 只控制 app 內預覽圖；「截圖」是占位；「音量」只改一個變數 |
| **購買主題沒有效果** | `theme_owned` 沒有任何地方套用 |
| **「幣」不會扣錢** | 主題／貼圖／禮物商店只跳確認框，不扣任何餘額；禮物買了不能送人 |
| **購物車看不到也不能結帳** | `taobao`、`delivery` 只有「加入購物車」，沒有購物車頁、結帳、訂單 |
| **三套互不相通的錢** | 支付餘額 10000、農場 `coins`、商店「幣」 |
| **餘額為 0 會被重設** | `kakaopay` 用 `if (savedBal)`，餘額 0 時被當成未儲存而重設為 10000 |
| 時間樹只能加「今天」 | 無日期選擇、無編輯／刪除 |
| 付款碼不是 QR | 只是一串隨機字 |
| 每日食譜只有 3 筆固定資料 | 不隨日期變化也沒有 AI |
| 聊天室「轉帳」只是跳到支付頁 | 沒有對角色轉帳 |

### 測試中發現並修掉的真實缺陷（不在原清單內）
| 缺陷 | 影響 |
|---|---|
| **13 個 app 存檔後畫面不更新**（呼叫 `renderXxx(params)` 但忽略回傳的元素） | 操作後要離開再進來才看得到結果 → 統一改用 `Router.handleRoute()` |
| 支付餘額為 0 時被重設為 10000（`if (savedBal)`） | 錢會憑空出現 |
| **`MemoryDB.create` 用白名單丟掉 `character_id`、`source_app`、`theater_ids`、`is_fiction`** | 所有 app 存的互動記憶都失去角色歸屬，依角色／劇場／來源檢索永遠是空的 |
| 記憶關鍵字檢索要求「整句查詢完整出現在記憶中」 | 沒啟用向量時，自然語句幾乎召回不到任何記憶 |
| 各 app 存的記憶沒有 embedding | 啟用向量檢索後這些記憶永遠找不到 → 補上關鍵字比對 |
| 聊天檢索記憶沒有按角色過濾 | 角色 A 的記憶可能出現在角色 B 的對話 |
| 定位座標、貼圖 emoji 等非文字訊息被當原文存進記憶 | 記憶裡出現「25.03300, 121.56540」之類的垃圾 → 改存可讀描述 |
| **個人 Wiki 缺少 `emojiBtn` 宣告** | `renderEditor` 在綁定事件前就丟例外：標題、區塊編輯、快捷鍵、復原重做全部失效（已提交版本就有） |
| Wiki 清單：初次載入沒有編號；CSS 沒有顯示編號；項目符號與待辦打勾字元亂碼 | 編號清單看不到數字 |
| Wiki 清單按 Enter 一律產生一般文字 | 清單被打斷 → 改為延續清單、空項目再按 Enter 結束清單 |
| 相簿「設為桌布」寫入 `wallpaper_url` 但主畫面從不讀取 | 設定無效 |
| 照相館儲存時沒有把濾鏡畫進圖片，且只能貼網址、不進相簿 | 存下來的是原圖 |
| 健康：沒有使用者面具時「新增」會在儲存時崩潰；藥名未跳脫；經期紀錄不能刪 | — |
| 谷子圖鑑 cleanup 重置篩選 | 重畫時篩選被洗掉 |

### 限制
- 螢幕截圖使用 `getDisplayMedia`，手機瀏覽器多半不支援（已有明確提示）；音量控制只作用於 `<audio>`／`<video>`（聊天語音、影片），不影響 Music app 的 Web Audio
- 付款碼 QR 使用 MIT 授權的 `qrcode-generator`（`js/vendor/`），已用 jsQR 反向解碼驗證；實際掃描需要對應的商家端，這裡只是示意用的付款碼
- 需要真實外部服務才能驗證的項目（Notion 同步、Bilibili 播放、紫微 MCP、Discord）未驗證

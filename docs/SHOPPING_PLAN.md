# 購物、禮物與共同基金：設計與決定

這份文件記錄使用者對禮物／錢包系統的決定與實作範圍（隨實作更新）。

## 使用者的決定
1. 共同基金：**每個角色各一個**。
2. 角色**會自己「出錢」**到共同基金（每週固定金額，可在角色設定調整，預設 $100，0 表示關閉）。
3. **送禮不增加好感度**，只是一種互相往來的行為（但會有反應與記憶）。
4. **回禮要**，但不是立刻回；**重要的日子**（生日、紀念日、節日）角色也要**主動送禮**。
5. 原本的假商店（6 件假商品、假物流）**不保留**，購物 App 改成連到現實購物網站。
6. 平台：蝦皮、momo、PChome、博客來、Pinkoi、Amazon，另加淘寶、拼多多、閒魚、煤爐（Mercari 日本）。
7. **要接真實價格**（用神秘門的「商品搜尋」工具，使用者自備搜尋服務金鑰；沒設定時價格標示為 AI 估計）。
8. 角色**主動提議**挑禮物：要。

## 做法的邊界
- 沒有辦法（也不該）直接讀取購物網站的商品與價格：用**搜尋連結**開啟外部網站，由使用者決定要不要買。連結只帶商品關鍵字，不帶任何個人資料；只能開啟預先列好的平台網域。
- 價格標示為「約」（AI 估計）；接上商品搜尋工具後才顯示真實價格與來源。
- 沒有背景推播：「主動」＝App 開啟時檢查重要日子，建立一張「他想送你東西」的待處理卡片；**使用者點開才呼叫 AI 生成**（不會偷偷花 API 額度）。

## 階段
1. 真實平台連結、角色挑禮、願望清單、重要日子主動提議（購物 App 重寫）。
2. 送禮的回應與記憶（你送給角色、角色送給你）、延遲回禮。
3. 街機廳賺錢包的錢（有每日上限）、共同基金（角色每週出錢、存錢目標、達標事件）。
4. 商品搜尋工具（神秘門）接真實價格；Discord 同步。
